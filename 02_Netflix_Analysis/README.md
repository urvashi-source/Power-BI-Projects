**📌 Project Overview**
* This project is a comprehensive analysis of the Netflix library, exploring the balance between movies and TV shows, global distribution, and content growth over time. The dashboard was designed with a high-fidelity "Netflix-style" UI/UX to provide an immersive data storytelling experience.

**📊 Key Insights & Data Storytelling**
* **The "Pandemic Gap":** Identified a significant decrease in new content releases for 2019, correlating with global production shutdowns and release delays.
* **Content Growth Trends:** Visualized a sharp exponential increase in titles added to the platform starting in 2015.
* **Regional Deep-Dive (India):** Discovered a unique market preference in India, with a library heavily skewed toward Movies (827) over TV Shows (5).
* **Library Composition:** Analyzed the dominance of TV-MA and TV-14 ratings and identified the most saturated genres across the platform.

**🛠️ The Data Pipeline**
* **Data Cleaning (Excel):** Performed initial auditing to remove duplicate records and handle null values.
* **Data Transformation (Python):** Utilized Python scripts to standardize inconsistent date formats and perform advanced data validation.
* **Visualization (Power BI):** 
    * Developed a **Dark-Mode UI** using branded color hex codes for a professional finish.
    * Integrated **Dynamic Slicers** for real-time filtering by Genre, Country, Year, and Content Type.
    * Implemented **Geospatial Mapping** to illustrate the density of Netflix's global footprint.

**📂 Project Structure**
* **Netflix_Analysis.pbix:** The primary Power BI dashboard file.
* **Cleaned_Netflix_Data.csv:** The final dataset after Python/Excel processing.
* **Screenshots:** Visual previews of the dashboard
