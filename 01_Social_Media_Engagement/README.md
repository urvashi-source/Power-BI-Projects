📱 Social Media Post Engagement Analysis

📌 Project Overview
This project focuses on analyzing user interaction across major social media platforms (Instagram, Facebook, and Twitter). The goal was to build a centralized dashboard that identifies which content formats and platforms drive the highest audience engagement to help inform data-driven marketing strategies.

📊 Key Insights & Findings
* Platform Dominance: Instagram emerged as the most active platform, accounting for the highest volume of posts.
* Content Efficiency: Donut chart analysis revealed that Image-based posts achieve the highest overall engagement rate compared to video or text.
* Performance Benchmarks: Established baseline KPIs for Average Likes, Comments, Shares, and Views to measure future campaign success.

🛠️ Technical Implementation
* Data Sourcing: Processed and cleaned a raw dataset sourced from **Kaggle**.
* Data Modeling: Established relationships between platform types, post formats, and engagement metrics.
* Interactive UI/UX: 
    * Implemented Gauge Charts to visualize performance against scale.
    * Integrated Slicers for platform-specific and post-type granular analysis.
    * Utilized KPI Cards for immediate executive-level data summaries.
